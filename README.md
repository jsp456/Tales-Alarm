# Tales Alarm

Tales Alarm은 Windows에서 두 개의 카운트다운 타이머를 동시에 독립 실행하는 트레이 앱입니다. 기본 설정은 타이머 1이 20분/F4, 타이머 2가 30분/F8이며, 창을 닫아도 타이머와 전역 단축키는 트레이에서 계속 작동합니다.

최종 배포 파일은 Windows x64용 자체 포함 단일 실행 파일입니다. 대상 PC에 .NET을 별도로 설치할 필요가 없습니다.

## 사용법

1. 시·분·초를 입력합니다. 범위는 `00:00:01`부터 `999:59:59`까지입니다.
2. 전역 단축키 입력 상자를 클릭하고 원하는 키 조합을 누릅니다. 두 타이머에는 서로 다른 단축키를 지정해야 합니다.
3. 타이머마다 단축키 재입력 동작을 선택합니다.
   - **처음부터 다시 시작**: 실행 또는 일시정지 중 같은 단축키를 누르면 전체 시간부터 다시 시작합니다.
   - **일시정지 · 재개**: 실행 중에는 일시정지하고, 일시정지 중에는 남은 시간부터 재개합니다.
   - **입력 무시**: 실행 또는 일시정지 중의 같은 단축키 입력을 무시합니다.
4. **설정 적용**을 눌러 시간·단축키·재입력 동작을 함께 저장합니다. 실행 중인 타이머의 남은 시간은 즉시 바뀌지 않으며, 다음 시작 또는 초기화부터 새 시간이 적용됩니다.
5. 화면의 **시작**, **일시정지 / 재개**, **초기화** 버튼으로도 각 타이머를 제어할 수 있습니다. 화면의 시작 버튼은 재입력 정책과 관계없이 항상 전체 시간부터 다시 시작합니다.

## 알람 음원

- 기본 음원은 앱에 포함된 1.5초 길이의 2음 차임입니다.
- **음원 변경**에서 WAV 또는 MP3를 선택하면 앱 데이터 폴더로 안전하게 복사하고 재생 가능 여부를 확인한 뒤 저장합니다.
- **미리 듣기**는 현재 선택한 음원과 화면에 입력된 재생 시간을 사용합니다.
- **기본음 복원**은 저장이 성공한 뒤 기존 관리 음원 파일을 정리합니다.
- 재생 시간은 `0.1`초부터 `60.0`초까지 0.1초 단위로 설정합니다. 음원이 더 짧으면 설정 시간까지 반복하고, 더 길면 설정 시간에 중지합니다.
- 사용자 음원을 열거나 재생할 수 없으면 해당 재생부터 기본 차임으로 대체하며 오류를 표시합니다.

## 창과 트레이

창의 닫기 버튼은 앱을 종료하지 않고 창만 숨깁니다. 트레이 아이콘을 두 번 클릭하거나 **열기** 메뉴를 선택하면 창이 다시 나타납니다. 프로세스를 완전히 끝내려면 트레이 메뉴의 **종료**를 선택하세요.

앱을 한 번 더 실행하면 새 타이머 프로세스를 만들지 않고 기존 창을 표시합니다. 전역 단축키가 다른 프로그램과 충돌하면 새 설정을 적용하지 않고 이전 단축키를 복원하며, 충돌 메시지를 화면에 표시합니다.

설정, 로그, 가져온 음원은 `%LocalAppData%\TalesAlarm` 아래에 저장됩니다. 손상된 설정 파일은 타임스탬프가 붙은 `settings.corrupt-*.json`으로 백업한 뒤 기본값으로 복구합니다. Windows 로그인 시 자동 시작 등록 기능은 포함되어 있지 않습니다.

## 개발 및 빌드

필요 환경은 Windows x64와 .NET 10 SDK입니다. 저장소 루트에서 다음 명령을 실행합니다.

```powershell
dotnet build src/TalesAlarm/TalesAlarm.csproj -c Debug
dotnet test TalesAlarm.sln -c Release
dotnet publish src/TalesAlarm/TalesAlarm.csproj -p:PublishProfile=win-x64
powershell -ExecutionPolicy Bypass -File tests/Verify-PublishArtifact.ps1 -PublishDirectory artifacts/TalesAlarm-win-x64
```

게시가 성공하면 최종 실행 파일은 다음 위치에 생성됩니다.

```text
artifacts/TalesAlarm-win-x64/TalesAlarm.exe
```

배포 폴더에는 실행에 필요한 별도 DLL, runtimeconfig/deps JSON, WAV 또는 ICO 파일이 없어야 합니다.
