# Tales Alarm 초소형 간단 보기 설계

## 목표

현재 `620×260` 크기의 간단 보기를 Windows 작업표시줄과 비슷한 높이의 한 줄 정보 스트립으로 줄인다. 사용자는 두 타이머의 번호, 남은 시간, 상태만 즉시 확인하고 필요할 때 상세 보기로 돌아갈 수 있어야 한다.

## 승인된 화면 구성

- 간단 보기 창은 WPF 장치 독립 픽셀 기준 `520×56`의 고정 크기로 표시한다.
- Windows 기본 제목 표시줄과 크기 조절 테두리를 제거한다. 여기서 무테두리는 네이티브 창 크롬을 뜻하며, 흰색 스트립의 경계를 구분하는 `1` DIP 콘텐츠 윤곽선은 유지한다.
- 한 줄 안에 다음 요소만 왼쪽부터 배치한다.
  - 타이머 1: 번호, 남은 시간(`HH:MM:SS` 또는 세 자리 시간), 상태
  - 세로 구분선
  - 타이머 2: 번호, 남은 시간, 상태
  - `상세` 버튼
  - `×` 버튼
- 앱 제목과 카드형 컨테이너는 간단 보기에서 표시하지 않는다.
- 시간은 약 `22px`의 고정폭 글꼴로 가장 눈에 띄게 표시하고, 번호와 상태는 약 `11~12px`로 표시한다.
- `일시정지`처럼 가장 긴 현재 상태 문구와 `999:59:59`가 잘리거나 겹치지 않아야 한다.

## 창 동작

- 간단 보기에서는 `WindowStyle=None`, `ResizeMode=NoResize`를 사용해 전체 창 높이를 `56`으로 맞춘다.
- `상세`와 `×` 버튼을 제외한 스트립 영역을 마우스 왼쪽 버튼으로 끌면 창을 이동할 수 있다.
- `상세` 버튼은 기존 `ToggleCompactViewCommand`를 사용한다.
- `×` 버튼은 기존 창 닫기 경로를 호출한다. 따라서 프로세스를 종료하지 않고 현재 동작과 동일하게 트레이로 숨긴다.
- 상세 보기로 돌아가면 기존 제목 표시줄, 크기 조절 방식, `1100×760` 기본 크기와 최소 크기를 복원한다.
- 상세 창이 최대화된 상태에서 전환해도 간단 보기는 먼저 보통 창 상태로 바뀐 뒤 `520×56`으로 표시한다.
- 보기 모드 저장, 타이머 진행, 전역 단축키, 알람, 트레이 동작은 기존 구현을 그대로 유지한다.

## 구현 경계

- `MainWindow.xaml`의 창 스타일 트리거와 `CompactTimerTemplate`, `CompactView` 레이아웃만 초소형 스트립에 맞게 변경한다.
- 전역 버튼 스타일의 `MinHeight=44`가 스트립 높이를 늘리지 않도록 간단 보기 전용 버튼 스타일에서 크기와 여백을 명시적으로 재정의한다.
- `MainWindow.xaml.cs`에는 스트립 드래그, 닫기 버튼, 간단 보기 전환 시 보통 창 상태 복원 처리만 추가한다.
- ViewModel, 설정 스키마, 타이머 모델에는 새 상태나 명령을 추가하지 않는다.

## 오류 및 경계 처리

- 드래그는 마우스 왼쪽 버튼이 눌린 경우에만 시작하며, `상세`와 `×` 버튼 클릭은 드래그로 처리하지 않는다.
- 창 닫기는 새 종료 로직을 만들지 않고 기존 `OnClosing` 처리를 통과시켜 트레이 숨김 의미를 보존한다.
- 표시 배율이 바뀌어도 WPF 장치 독립 픽셀을 사용하므로 운영체제 UI와 함께 자연스럽게 배율이 적용된다.

## 검증

- 실제 WPF 창을 구동하는 통합 테스트로 간단 보기의 `520×56` 크기, 네이티브 창 크롬 제거/크기 고정 설정, 필수 정보 표시와 `상세`/`×` 컨트롤 동작을 확인한다.
- 실제 버튼 호출로 `상세` 전환과 `×` 숨김을 검증하고, 트레이에서 다시 표시한 뒤에도 간단 보기 크기와 창 스타일이 유지되는지 확인한다.
- 전체 Release 테스트와 WPF 빌드를 실행한다.
- 게시된 단일 EXE를 실행해 다음을 직접 확인한다.
  - 간단 보기 전환 시 한 줄 높이로 줄어드는지
  - 두 타이머의 최대 길이 시간과 모든 상태가 겹치지 않는지
  - 스트립 드래그, 상세 복귀, `×`를 통한 트레이 숨김이 동작하는지
  - 최대화된 상세 창에서도 간단 보기가 `520×56` 보통 창으로 전환되는지
  - 상세 보기로 돌아왔을 때 기존 레이아웃과 창 동작이 유지되는지

## 제외 범위

항상 위 표시, 화면 가장자리 자동 스냅, 간단 보기 위치 저장, 사용자 지정 크기, 간단 보기 안의 타이머 조작 버튼은 이번 변경에 포함하지 않는다.
