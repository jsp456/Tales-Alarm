# Tales Alarm 간단 보기 설계

## 목표

기존 상세 화면과 별도로 두 타이머의 핵심 상태만 빠르게 확인할 수 있는 작은 간단 보기 모드를 제공한다. 사용자가 선택한 보기 모드는 앱을 다시 실행해도 유지한다.

## 사용자 경험

- 상세 화면 상단에 `간단 보기` 버튼을 둔다.
- 간단 보기에는 각 타이머의 번호, 남은 시간(`HH:MM:SS`), 상태만 표시한다.
- 간단 보기 상단의 `상세 보기` 버튼으로 기존 화면에 돌아간다.
- 간단 보기로 전환하면 창을 작은 고정 기본 크기로 줄이고, 상세 보기로 돌아가면 기존 상세 크기로 복원한다.
- 타이머 실행 상태, 전역 단축키, 트레이 동작과 창 닫기 동작은 보기 전환의 영향을 받지 않는다.

## 구조

- `AppSettings`에 기본값이 `false`인 `UseCompactView` 값을 추가한다. 기존 JSON에 값이 없어도 상세 보기로 정상 로드되도록 선택적 생성자 기본값을 사용하고 스키마 버전은 유지한다.
- `MainViewModel`이 `IsCompactView`와 `ToggleCompactViewCommand`를 제공한다. 전환 즉시 현재 세션의 화면을 바꾸고 전체 설정을 저장한다.
- 기존 타이머·음원 설정을 적용할 때도 `UseCompactView` 값을 그대로 보존한다.
- 저장 실패 시 화면 전환 자체는 유지하고 기존 전역 상태 메시지와 로그 경로를 통해 실패를 알린다. 다음 실행에서는 마지막으로 성공적으로 저장된 모드가 사용된다.
- `MainWindow.xaml`은 하나의 창 안에 상세/간단 레이아웃을 두고 `IsCompactView`에 따라 한쪽만 보이게 한다. 별도 창이나 별도 타이머 인스턴스는 만들지 않는다.
- 창 크기 전환은 `MainWindow`가 담당하며 상세 크기 `1100x760`, 간단 크기 `620x260`을 사용한다.

## 검증 범위

- 기존 설정 JSON에 새 필드가 없어도 상세 보기로 로드되는지 확인한다.
- 보기 전환이 상태를 바꾸고 저장 설정에 반영되는지 ViewModel 테스트로 확인한다.
- WPF 빌드와 게시 EXE 기동으로 XAML 로드 및 화면 구성 오류를 확인한다.
- 전체 Release 테스트를 한 번 실행하고 Windows x64 단일 EXE를 다시 게시해 기동 검증한다.

불필요한 창 위치 저장, 사용자 지정 간단 보기 크기, 간단 보기 내 타이머 조작 버튼은 범위에서 제외한다.
